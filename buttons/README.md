# Buttons

可编辑的功能按钮抽屉，插件 ID：`io.soloev/buttons`，需要 Noctalia plugin API 46。

## 使用

- 在栏中添加 Buttons 组件，点击打开抽屉；也可以在 Quick Settings / 控制中心中添加 Buttons 快捷入口。
- IPC：`noctalia msg panel-toggle io.soloev/buttons:drawer`。
- 点击「新增」，填写名称、悬停提示、图标名称和 Shell 命令，点击「保存」。提示留空时显示名称，图标留空时使用 `terminal`。保存不会执行命令。
- 普通模式点击按钮执行命令；「编辑」模式点击按钮打开编辑器，不执行命令。编辑器支持前移/后移（同时保存当前编辑）和两次点击确认删除。
- 编辑模式下，右键一张卡片进入排序选择状态，卡片显示高亮边框；再右键另一张卡片交换两者顺序并立即保存。可以翻页后选择第二张卡片；再次右键原卡片或退出编辑模式取消选择。保存失败保留原顺序和选择，可重试。
- 「布局」可设置 1–5 行、1–6 列及启动后是否关闭抽屉；默认 3 行 4 列。超出每页容量的项目分页显示，支持上一页/下一页按钮和 Page Up / Page Down。
- 面板固定为 560×540，默认附着于栏。面板位置、放置方式使用宿主的面板设置。
- 插件设置中可开启「聚焦模式」：只显示按钮网格和翻页组件，只有一页时隐藏翻页。`Ctrl+E` 临时切换编辑模式，以显示标题、新增、编辑和布局等管理控件；完成编辑后恢复聚焦视图。设置在重新打开面板时读取。
- 编辑器与布局使用显式保存；取消、关闭或点击面板外部会丢弃未保存内容。

当前标准宿主 API 46 不支持插件动态调整面板外框尺寸，因此布局内的整体宽高设置暂缓，维持标准宿主兼容。

## 命令语义

当前只支持 Shell 动作。命令原文通过 `noctalia.runAsync` 交给 `/bin/sh -c`，支持管道、引号、重定向、多行命令及环境变量。使用宿主进程的环境和工作目录，不保证加载交互式 Shell 配置；需要时在命令中显式指定 `cd`、环境变量或解释器。不会自动打开终端。普通卡片不等待进程结束。

普通卡片的「启动后关闭」表示宿主接受了启动请求，不表示命令已经成功完成。启动请求被拒绝时保留抽屉并显示错误；聚焦模式通过通知报告错误。

## 状态卡片

每个启动项编辑器提供「状态模式」和默认状态（0 / 1）。默认图标复用该启动项的图标设置。旧版本数据缺少这两个字段时，按普通卡片、默认状态 0 处理，不自动执行命令。

状态卡片点击后执行其 Shell 命令并获取标准输出，超时为 10 秒。命令应以退出码 0 结束，stdout 只包含一条结果：

```text
0
1 moon
```

格式为 `$status $icon`，其中 `$status` 必须为 `0` 或 `1`，`$icon` 可省略；图标与状态间用空格或 Tab 分隔，允许首尾空白及结尾换行。状态 0 使用原有普通卡片配色，状态 1 使用 `primary` 背景与 `on_primary` 图文；图标存在时替换当前显示图标，省略时回退到启动项配置图标。请将调试信息输出到 stderr，不要混入 stdout。

状态命令执行期间卡片变淡并阻止重复执行；状态卡片始终保持抽屉打开，以显示结果，不受普通卡片的「启动后关闭」设置影响。退出码非 0、超时、输出被截断或格式无效时保留上一次状态，并显示错误；聚焦模式使用通知。

已获取的状态只保留在插件运行会话中，关闭再打开面板会保留，插件重载后使用默认状态。修改启动项的命令、图标、状态模式或默认状态会重置其运行状态；过期命令回调不会覆盖已修改或删除的卡片。状态输出不写入 JSON；保存的默认状态及图标用于每次新会话的初始显示。当前没有轮询或单独的查询命令，打开面板不会执行任何启动项命令。

## 存储

数据保存在 `noctalia.pluginDataDir()/items.json`，由宿主解析路径，升级插件时保留；所有栏及快捷入口使用同一份数据。没有预置命令。结构示例（仅说明格式）：

```json
{
  "version": 1,
  "rows": 3,
  "columns": 4,
  "close_on_run": true,
  "next_id": 2,
  "items": [
    {
      "id": "button-1",
      "name": "示例",
      "tooltip": "显示一条通知",
      "glyph": "terminal",
      "state_mode": false,
      "default_status": 0,
      "action": { "type": "shell", "command": "notify-send 'Hello'" }
    }
  ]
}
```

启动项最多 200 个；名称最多 160 字节，提示 512 字节，图标名 80 字节，命令 16384 字节；JSON 最大 256 KiB。不接受空白名称、空白命令或 NUL 字符。名称可以重复，内部 ID 必须唯一。宿主会将空 Luau 表编码为 `{}`，因此 `items: {}` 与 `items: []` 均表示空列表。

保存先写同目录的 `items.json.pending`，再重命名替换正式文件；保存失败保留当前编辑和原文件。读取失败、格式损坏、未知版本或未知动作类型会阻止编辑写入，避免覆盖数据。可修复文件后重新打开。打开时读取最新文件，保存前检查其他实例或外部修改，发现变化时要求重新打开；这不是跨进程文件锁，不支持并发写入。请不要同时在多个输出上保存编辑。空列表是有效状态。

## 验证

工作区根目录运行 `python3 -B harness/buttons/manifest.py` 检查入口 ID 全局唯一、入口文件及目录版本一致，再运行 `lua harness/buttons/drawer.lua`。这些检查位于发布仓库外，使用内存文件系统和 mock 进程，不读取用户配置、不执行真实命令。

需要人工 GUI 验证：

1. 添加栏入口及控制中心快捷入口，确认都能打开抽屉，面板外点击可关闭。
2. 新增两个无副作用测试命令，确认名称、悬停提示、图标和点击命中正确；保存/编辑不会执行命令，普通点击只执行对应命令。
3. 编辑名称、提示和多行命令；取消后不保存，保存后关闭再开仍存在。前移/后移顺序正确，删除需要确认，可删除到空列表。
4. 切换 1×1 与 5×6，增加超过一页的项目，确认分页、末页空位、翻页边界正确。分数缩放下检查名称、工具栏及编辑器滚动没有裁切。
5. 关闭「启动后关闭」，执行后应保留抽屉；再次开启后，启动请求被接受时应关闭抽屉。
6. 开启聚焦模式：单页仅见网格，多页出现翻页；`Ctrl+E` 显示管理控件，完成编辑后恢复聚焦。空列表时可用该快捷键新增。
7. 编辑模式依次右键两张卡片（包括跨页），确认高亮、交换、取消和重新打开后的顺序；普通模式右键不排序、不执行命令。
8. 将测试卡片设为状态模式，命令使用 `printf '1 moon\n'`，默认状态 0：打开时显示普通配色，点击后变为 primary 配色及 moon 图标，抽屉保持打开。改用 `printf '0\n'` 后点击，确认恢复普通配色及配置图标。
9. 默认状态改为 1 并保存，确认立即以启用形态显示；测试 `printf 'invalid\n'` 和 `exit 1`，确认保留原状态并报告错误。执行期间重复点击不启动第二个命令。

无界面测试不能证明真实 Luau CPU 预算、主题字形、输入焦点、原生渲染与分数缩放正确。
