# 屏幕键盘架构

栏按钮、控制中心快捷开关和服务 IPC 打开 `keyboard=none` 的 layer-shell 浮层。浮层按标准美式 87 键布局发送键码请求；后台服务维护可见状态、点选式单次修饰键、串行按键队列和鼠标拖动状态。

服务首次显示键盘时启动 Python 标准库辅助进程。该进程通过 `/dev/uinput` 建立一个常驻虚拟键盘，在插件私有数据目录内监听 Unix socket，校验请求并发送 evdev 按下/释放事件。每个请求均释放其按键和修饰键；进程退出时关闭 uinput 设备。服务关闭后，宿主终止其托管子进程。

输入经过合成器及应用的正常输入法路径，不使用剪贴板、文本提交协议或物理输入设备监听。Caps Lock 使用真实键码；界面指示仅跟踪本虚拟键盘的操作，不同步物理键盘的锁定指示。主机当前键盘布局决定字符映射；键帽按 US 布局显示。

界面采用 15 单位主键区、独立编辑区和方向键区。Shift/Ctrl/Alt/Super/AltGr 点击选中，再点击普通键发送一次组合并取消选中；再次点击选中的修饰键可取消。Caps Lock 为持续切换。隐藏键盘清空排队中的按键及未使用的修饰键。

顶部拖动条使用 `ui.pixelStream` 的命名指针回调获得鼠标捕获。辅助进程在私有 `drag.sock` 提供一个透明的 1×1 RGBA 密封 memfd，通过像素流协议传递一次静态画面；连接空闲时不重复发送画面。拖动条绘制文字提示，鼠标按下后在当前屏幕内拖动整个键盘，松开或取消时保存位置。辅助像素流失败时仍可使用位置按钮和键盘输入。

拖动期间浮层暂时覆盖当前输出，捕获控件的绘制变换扩展到该输出，键盘内容按位置平移。坐标空间保持在屏幕原点，避免移动窗口时局部坐标跳动和拖出细窄手柄后被钳制。首次布局后的帧回调启用移动事件；捕获结束后恢复为键盘大小的浮层。命名回调跨渲染保持不变，避免宿主因回调替换取消拖动。不声明文本或按键回调，浮层保持无键盘焦点。

标题栏的“位置 / 尺寸”按钮展开位置和尺寸控制：方向按钮按可移动范围的 5% 移动，宽度按 80 单位调整，键帽高度按 8 单位调整，并提供居中、贴底和重置。宽度范围 640–2400、键高范围 32–96，默认宽 1060、键高 48。按钮和拖动均不发送按键；尺寸通过按钮调整。

服务将横纵位置保存为可移动范围的百分比，将目标宽度和键帽高度保存在插件私有数据目录的 `geometry.json`，通过同目录临时文件原子替换。拖动过程只更新内存和显示，捕获结束时写入一次。每次打开和显示器变更时，服务按显示器逻辑尺寸和宿主 UI 缩放计算实际大小，保留 8 像素边距并限制在屏幕内。屏幕较小时只限制实际显示尺寸，保留用户保存的目标尺寸。

依赖 Python 3 和对 `/dev/uinput` 的读写权限；不依赖网络或额外 Python 包。设备仅在用户首次打开键盘时创建，键盘重开复用该设备。没有 GUI 自动化或真实按键注入测试。
