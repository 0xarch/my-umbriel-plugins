# 屏幕键盘架构

栏按钮、控制中心快捷开关和服务 IPC 打开 `keyboard=none` 的 layer-shell 浮层。后台服务维护可见状态、点选式单次修饰键、串行按键队列、键盘位置与鼠标捕获状态。美式 87 键布局在 `view.luau` 中共用，实际键盘和拖动预览使用同一视图函数。

Python 标准库辅助进程通过 `/dev/uinput` 建立常驻虚拟键盘，在插件私有数据目录监听 Unix socket 并校验请求。每次按键请求均发送完整的按下和释放序列；进程关闭时销毁虚拟设备。宿主停止后台服务时终止其托管子进程。

输入经过合成器及应用的正常输入法路径，不使用剪贴板、文本提交协议或物理输入设备监听。Caps Lock 指示跟踪本虚拟键盘的操作，不同步物理键盘锁定状态。主机键盘布局决定字符映射，键帽按 US 显示。Shift/Ctrl/Alt/Super/AltGr 点选后对下一个普通键生效，随后释放。

顶部功能区高 34 逻辑单位，中间是 `arrows-move`、`filter-cancel` 和关闭三个纯图标按钮，左右是等宽拖动区。功能区不显示标题或状态文字，操作提示通过按钮 tooltip 提供。刷新按钮仅用于设备启动失败后的重试，界面通过再次点击按键或重开键盘触发恢复。两侧拖动区使用 `ui.pixelStream` 的命名指针回调获得鼠标捕获。辅助进程在私有 `drag.sock` 和 `drag-right.sock` 提供一个透明 1×1 RGBA 密封 memfd，通过像素流协议传递一次静态画面，空闲时不重复发送。捕获控件的绘制变换覆盖相对表面原点的负一屏至正两屏区域，使向上和向左移动保持有效。

实际键盘表面在拖动期间维持原始位置、大小和坐标原点，只隐藏绘制，继续持有鼠标捕获；单独的全屏透明预览层显示拖动后的键盘。预览层设置 `click_through=true` 和 `keyboard=none`，不阻挡其他表面的输入。按下坐标直接建立参考点，移动按帧合并，松开后更新实际表面位置、显示实际键盘并隐藏预览。无需改变捕获表面的原点或等待一次鼠标移动来校准。取消、隐藏、输出变更和辅助进程退出均结束捕获。

位置以逻辑像素保存，旧版百分比位置在首次定位时作为默认值读取。上边界保留 8 像素，左边界为 `60 - 键盘宽度`，右边界为 `屏幕宽度 - 60`，下边界为 `屏幕高度 - 60`，允许大部分键盘越出屏幕但保留可见区域。屏幕尺寸和宿主 UI 缩放决定实际键帽大小；屏幕较小时限制实际尺寸并保留用户设置的目标尺寸。

`arrows-move` 按钮提供方向移动、宽度与键高调整、居中、贴底及重置。宽度范围 640–2400，键高范围 32–96，默认宽 1060、键高 48。居中、贴底和重置可恢复屏幕内的位置。方向按钮每次移动屏幕尺寸的 5%，宽度每次调整 80 单位，键高每次调整 8 单位。调整按钮和拖动不发送按键。

目标尺寸、位置写入私有数据目录的 `geometry.json`，通过同目录临时文件原子替换。拖动仅更新内存和预览，在结束时保存一次。依赖 Python 3 和 `/dev/uinput` 的读写权限，不依赖额外 Python 包和网络。验证使用隔离的协议及状态测试，真实输入和拖动手感由用户人工验证。
